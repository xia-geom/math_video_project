| Material | Applicable source to inspect |
| --- | --- |
| Video code and original project utilities | [Root license](LICENSE), with any file-specific notices retained |

| Logos and institutional branding | Original rightsholder's terms and intended-use approval; a code license is not an institutional endorsement |
| Fonts, music, other externally obtained assets | Their own licenses; no implicit permission to redistribute a local machine's installed fonts |
| Rendered films and other exports | Relevant code, media and document terms together; a render passing tests does not clear its incorporated assets |

Before publishing a derived film, preserve attribution and resolve any unclear
permission for the intended distribution. Existing original files and notices
remain intact; this audit does not certify all media rights or institutional
approval. Use invented content for security tests and public bug reproductions.
