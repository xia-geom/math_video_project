# Erreurs frequentes

This category contains French lessons designed around common student mistakes.
Each lesson belongs in its own topic folder:

```text
scenes/erreurs_frequentes_fr/<topic_slug>/<topic_slug>_scene.py
```

Do not relocate existing subject lessons here solely because they mention a
common mistake. This category is for videos intentionally designed around one.
