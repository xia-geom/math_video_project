# Erreurs fréquentes en mathématiques

Cette catégorie regroupe les capsules construites autour d’un raisonnement tentant, mais invalide. Chaque scène présente l’erreur, montre pourquoi elle échoue, puis propose une méthode fiable pour la remplacer.

Une capsule n’est pas classée ici simplement parce qu’elle mentionne une erreur. Son objectif pédagogique principal doit être le diagnostic et la correction d’une méprise fréquente.

Chaque leçon possède son propre dossier :

```text
scenes/erreurs_frequentes_fr/<topic_slug>/<topic_slug>_scene.py
```
