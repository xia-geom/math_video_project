# Le signe du dénominateur dans une inéquation

Objectif : résoudre un quotient de signe imposé sans multiplier par une
expression dont le signe est inconnu.

Prérequis : ordre dans les réels, signe d’un produit, intervalles.

Exemple du cahier : \((x+2)/(x-3)>0\). Un curseur parcourt trois valeurs tests ;
le tableau explique pourquoi le signe reste constant entre les valeurs
critiques. Les deux demi-droites finales excluent \(-2\) et \(3\), avec une
explication distincte pour chacune.

Références : manuel MAT0339, chapitre 2, « Inéquations et tableaux de signes »
et « Résoudre sans perdre d’information » ; cahier, exercice 2.4C et synthèse
du chapitre 2, S3. Les sources actives sont
`books/mat0339/sources/manual/chapters/ch02.tex` et
`books/mat0339/sources/workbook/chapters/ch02.tex` ; le même exemple 2.4C
est conservé dans l’édition du 10 octobre et la révision du 17 octobre 2026.

Le cas de synthèse \((x-1)/(x+2)\le2\) montre pourquoi il faut d’abord ramener
l’inéquation à zéro : elle équivaut, pour \(x\ne-2\), à
\((x+5)/(x+2)\ge0\). Sa solution est
\(]-\infty,-5]\cup]-2,+\infty[\). Le signe du quotient initial ne suffit pas.

Autoévaluation originale, avec six secondes de réflexion :
\((x-1)/(x+2)\le0\). Réponse : \(]-2,1]\), avec \(-2\) interdit et \(1\) admis.
