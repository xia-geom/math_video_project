# Modern visual system for this storyboard

## Background

Use a clean, nearly white background:

```python
background = "#F7F8FA"
surface = "#FFFFFF"
ink = "#18212B"
muted = "#69737D"
grid = "#E6E9ED"
```

The present theme relies on several filled course-category colours and matching border colours.  For v3, the base table should be mostly neutral, with colour appearing only when a branch or course family is discussed.

## Branch accents

```python
math = "#3157D5"
statistics = "#008A7A"
computing = "#E15B45"
complementary = "#F2E6C9"
```

## Cards

* corner radius: 14–18 px;
* no thick black outline;
* 1 px neutral border;
* very subtle shadow;
* highlighted card uses a narrow coloured side rail;
* non-highlighted cards at 20–30% opacity.

## Course labels

During normal explanation:

> Analyse

not:

> MAT2150 — Analyse II

Exact codes appear only in detailed still images, not in the explanatory video.

# Synchronization specification

The current renderer calculates animation progress as the scene time divided by the full audio duration.  It also estimates subtitle timing according to relative word count rather than actual speech boundaries.  This is why the movement can be technically the same duration as the audio but still feel unsynchronized.

For v3, each narration sentence should have explicit markers:

```python
Cue(
    start=0.00,
    end=2.60,
    action="show_table_frame",
)

Cue(
    start=2.60,
    end=5.10,
    action="highlight_autumn_row",
)

Cue(
    start=5.10,
    end=7.80,
    action="highlight_winter_row",
)
```

Use:

* **30 fps**;
* 0.35–0.55 second eased movements;
* at least 0.7 second visual hold after each reveal;
* no continuous movement while the narrator introduces a new concept;
* movement should begin slightly before the key spoken word and settle just after it;
* no proportional word-count subtitle timing for the final version.

The voice recording or TTS audio should be finalized **before** the final animation timing.
